# Real-Time IT Stock Analysis using RNN & LSTM

Predicts next-day closing prices for Indian IT-sector stocks (TCS, Infosys, Wipro, HCLTech, TechMahindra, Persistent Systems, Zensar Technologies) using Recurrent Neural Networks, compares prediction performance across large-cap, mid-cap, and small-cap companies, and fuses the model's technical signal with live news sentiment — all wrapped in an interactive Streamlit dashboard.

## Problem Statement

Stock price movement is sequential and time-dependent, making it a natural fit for Recurrent Neural Networks. This project builds, trains, and evaluates RNN and LSTM models on historical IT-sector stock data, extends the analysis to study how company scale (market capitalization) affects prediction accuracy, and combines the model's technical output with real-time news sentiment into a single, explainable signal.

## Features

- **RNN vs LSTM comparison** — built and evaluated both architectures on the same data for a fair comparison.
- **Multivariate feature engineering** — Open, High, Low, Close, Volume, 50-day/200-day Moving Averages, and RSI, fed through a 60-day sliding-window sequence.
- **Time-based train/test split** — no shuffling, avoiding data leakage in time-series data.
- **Market-cap comparison** — repeats training across a large-cap, mid-cap, and small-cap IT stock to study how company scale relates to prediction error and volatility.
- **Real-time prediction** — pulls the latest available market data and predicts the next closing price on demand.
- **Live news sentiment** — fetches recent headlines (Google News RSS) and scores them with VADER sentiment analysis.
- **Fusion recommendation** — combines technical trend, RSI momentum, the LSTM's own prediction, and news sentiment into one rule-based, fully explainable signal.
- **Interactive Streamlit dashboard** — OHLC candlestick charts across 9 timeframes (1D to All-time), a multi-stock market overview table, and the fusion signal, all in one app.

## Approach

1. **Data Collection** — Historical daily OHLCV data pulled via the Yahoo Finance API (`yfinance`), covering 3+ years per stock.
2. **Feature Engineering** — Multivariate input: Open, High, Low, Close, Volume, Moving Averages, and RSI.
3. **Preprocessing** — MinMax scaling, 60-day sliding-window sequence generation, and a time-based train/test split.
4. **Modeling** — Simple RNN and LSTM, evaluated using RMSE and MAE against a naive baseline forecast.
5. **Market-Cap Comparison** — Large-cap, mid-cap, and small-cap IT stocks compared on prediction error and volatility.
6. **News Sentiment Fusion** — Recent headlines scored with VADER and combined with the technical signal into one recommendation.
7. **Deployment** — A Streamlit dashboard for live, interactive predictions.

## How to Run

### Option 1: Notebook (Colab)
1. Upload `Realtime_IT_Stock_RNN_Project.ipynb` to Google Colab.
2. Runtime → Run all.
3. No manual data download needed — the notebook fetches live historical data via `yfinance`.

### Option 2: Streamlit Dashboard (local)
```bash
pip install -r requirements.txt
streamlit run app.py
```
Requires the trained model files generated by running the notebook.
